# v0.10.15 验收记录

日期：2026-10-20。

- 在完成按钮上方常驻显示「上次记录：第 N 行 · HH:mm:ss」，沿用预览的字号、颜色和间距。无时间数据时显示「暂无记录时间」。
- 每条作品新增可选 completedAt 行号到时间戳映射，与 completed 在同一笔保存中提交；保存失败或保存待确认期间不提前更新成功提示。
- 撤销/取消勾选会移除对应时间并回到上一条仍有效的记录；修改设置和设为最宽处仅保留仍有效行的时间。续织补录和旧存档不补造历史时间。
- 重开、刷新及作品切换恢复各自记录。当天显示秒，跨天显示昨天或日期，跨年包括年份。可选时间损坏不影响原有行进度。
