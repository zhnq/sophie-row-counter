## 用户验收

打开 `http://127.0.0.1:4173/`，新建或打开围巾设置：

1. 选择手法，将首个、后续加针前下针数填为 2、3。
2. 按自己的织图填写最宽针数、首次加针行、间隔与尾段，点击预览。
3. 核对前两次加针的针上／针间位置和各区块数量，再保存计数。
4. 勾选一行、退回、重开设置，核对保存恢复。
