# 苏菲围巾计数：调研与计数规则

版本：v0.3；更新日期：2026-10-03。

本项目是小红书小工具：使用离线 HTML、CSS、JavaScript，按用户自己的织图生成计数表。它记录行数、变针位置、织后针数和完成状态，不提供官方 Sophie 的完整逐行织图，也不保证按默认参数得到官方尺码。

## 1. 调研依据

### 官方公开事实

[PetiteKnit 的 Sophie Scarf 页面](https://www.petiteknit.com/en/products/sophie-scarf)确认：围巾从一个尖端到另一个尖端来回平织，采用搓板针和一体 i-cord 边；小号约长 80 cm、中心宽 11 cm，大号约长 102 cm、中心宽 13 cm。参考密度为每 10 cm 22 针 × 42 行，参考针号为 3.5 mm。官网公开列出起织、KFB、SKP 和收针视频，完整织图以付费 PDF 提供。

这些信息可以确定工具的技术方向，不能确定官方各尺码的最宽针数、转折行或最后平织行数。因此新建时不预填最宽针数和末尾平织行数，不设未经核实的“官方小号／大号”按钮。

[Craft Yarn Council 的缩写标准](https://www.craftyarncouncil.com/standards/knitting-abbreviations)定义 KFB 为同一针前后各织一次，消耗 1 个原针，产生 2 针；SKP 消耗 2 个原针，产生 1 针。[The Knitting Guild Association 的加针资料](https://www.tkga.org/wp-content/uploads/issue_archives/2019/Fall/BS_SB_Skill%20Building%20Upload.pdf)说明 M1 从相邻两针之间的横线生成新针，不消耗原针。两种加针都增加 1 针，但行内普通下针数量不同。

### 实织旁证

- [knittingchick50 的完成作品笔记](https://www.ravelry.com/projects/knittingchick50/sophie-scarf)把原做法描述为在第 3 针 KFB，然后记录自己改成织完前 3 针后提针或 M1R、减针也移到前 3 针之后。这里的“先 2 针”和“先 3 针”属于不同操作方案，不能只换技法名称而保留下针数量。
- [MyCraftingJournal 的修改笔记](https://www.ravelry.com/projects/MyCraftingJournal/sophie-scarf)记录：首次加针改为两个 i-cord 边之间起出新针，后续加针改在边针之后；最后先织 2 针，把第 3、4 针合并，回到 6 针。这支持首个加针行和末次减针行分别配置位置。
- [Conscious by Chloé 的 Sophie 实织记录](https://consciousbychloe.com/2026/03/11/sophie-scarf-petiteknit-pattern-review/)描述每 8 行变针、在同一布边加减、每行末尾滑 3 针且线在前，并记录自己第二条在 22 针转入减针。它支持计数器的使用场景和自定义宽度，不构成官方尺码表。
- [Knitting in English 的公开课程目录](https://knitting-in-english.teachable.com/p/sophiescarf)把第 1–7 行、从第 8 行开始加针、减针和收针列为不同章节。实际逐针课程需购买证明；本项目没有读取其付费内容。

上述资料是用户或教师的一手记录，不能代替官方完整织图校准。首次事件、转折、末尾平织和收针仍以用户所持织图为准。

### 独立免费变体

[Oolong Knits 的 Sofia’s scarf](https://oolongknits.blogspot.com/2022/12/wip-sofias-scarf.html)是作者独立公开的类似结构设计。作者明确未购买 PetiteKnit 原版，采用葡萄牙式上针写法和自己的起收针方式。[Laines du Nord 的 Big Sophie Scarf](https://www.lainesdunord.it/en/pdf-pattern/359/big-sophie-scarf/)采用先织 3 针、针内加针和不同起针数及间隔。这些资料可用于检验通用计数模型，不能作为官方 Sophie 预设。

未采用付费织图镜像或第三方转载全文。工具也不重建或分发完整付费织图。

## 2. 用户截图的范围

第一张截图直接支持：129–135 行为 22 针，136 行加针后 23 针，144 行后 24 针，152 行后 25 针，160 行后 26 针；变针相隔 8 行，两次变针之间有 7 行平织。

第二张截图是减针：112 行减到 11 针，120 行减到 10 针，128 行减到 9 针，136 行减到 8 针。若编号为减针段内行号、首减在第 8 行，则可从 25 针起点解释。两张图行号重叠且同一编号针数不同，不能拼成一份官方整条织图。

黄色、绿色表示相邻的平织组，蓝色表示加针或减针行；颜色不绑定某个固定针数。每行的具体动作由区块文字和位置表达。

## 3. 新建参数

| 参数 | 新建值 | 含义 |
| --- | --- | --- |
| 计数范围 | 整条围巾 | 也可只计加针段或减针段 |
| 起针数 / 结束针数 | 6 / 6 | 包含边针；按个人织图调整 |
| 最宽针数 | 留空，必填 | 由个人织图或实际计划确定 |
| 加减针间隔 | 8 行 | 两次变针的行号差；不是中间平织行数 |
| 首次加针行 | 8 | 加针段内行号 |
| 减针段首次减针行 | 8 | 从减针段第 1 行重新计数 |
| 中间平织行数 | 0 | 最后加针之后、减针段之前额外追加的行数 |
| 末尾平织行数 | 留空，必填 | 计数段末尾追加；整条时在最后减针后，不需要时明确填 0 |
| 末尾滑针数 | 3 | 计入行内原针数量 |
| 加针手法 | 针内加针 | 可改针间加针，改变普通下针数量 |
| 加针行首下针数 | 2 | incLead；不适用于首次加针行 |
| 首个加针行下针数 | 2 | firstIncLead；单独设置起尖位置 |
| 减针行首下针数 | 3 | decLead；不适用于末次减针行 |
| 末次减针行下针数 | 2 | lastDecLead；单独设置末尖位置 |
| 加针方式 / 首次位置 | 单侧 / 行首 | 每个事件总共只加 1 针 |
| 减针方式 | 沿用加针侧 | 也可独立选单侧或左右交替，并设置首次位置 |
| 收针记录 | 最后一行收针 | 可选暂不记收针；仅整条或减针段生效 |
| 已完成行数 | 0 | 表示从第 1 行开始连续完成的行数 |
| 每 10 cm 行数 | 42 | 只作长度估算；使用自己的样片密度更合适 |

针数允许 6–200，间隔允许 2–40 行，总表不超过 4000 行。最宽针数须高于所计加针段的起针数、所计减针段的结束针数。参数不适配某个变针行时，生成直接报错，不截短下针、不生成负针数，也不把错误隐藏在“查看织图”行中。

切换加针手法时，界面只对仍为建议值的 incLead 和 firstIncLead 做 2 ↔ 3 调整；自定义数字保留。用户仍需核对位置，尤其从旧计划切换手法时。每行不展示 KFB、M1、SKP 等技法名。

## 4. 行内区块与针数守恒

before 是织前总针数，lead 是该行保留的行首普通下针，slip 是末尾滑针。加针使用 firstIncLead 或 incLead；减针使用 lastDecLead 或 decLead。

- incMethod: stitch：针内加针消耗 1 个原针，普通中间下针数为 before − lead − slip − 1。
- incMethod: between：针间加针消耗 0 个原针，普通中间下针数为 before − lead − slip。
- 减 1 针消耗 2 个原针，普通中间下针数为 before − lead − slip − 2。
- 平织行只分为 before − slip 下针与末尾滑针两块。

行首变针按“行首下针 → 变针 → 中间下针 → 滑针”显示；行尾变针按“行首下针 → 中间下针 → 变针 → 滑针”显示。行尾变针仍保留行首下针的独立块，变针块位于滑针之前。数量为 0 的下针块省略。

例如织前 22 针、行首先织 3 针、末尾滑 3 针：针内加针应显示 3 下针 / 单侧加针 / 15 下针 / 滑 3 针；针间加针则应为 3 下针 / 单侧加针 / 16 下针 / 滑 3 针。两者织后都是 23 针，但不能共用中间数量。

起尖和末尖可分别校准：6 针首加使用针内法时，2 下针 + 1 个变针原针 + 滑 3 针 = 6；使用针间法时，3 下针 + 0 个变针原针 + 滑 3 针 = 6。7 针末减使用 2 下针 + 2 个变针原针 + 滑 3 针 = 7，织后为 6 针。这些关系说明低针数可以通过正确位置生成有效区块，不必跳过计数；具体手法以织图为准。

## 5. 布边与编织方向

“单侧”表示始终同一布边；“左右”表示两条布边按变针事件交替。它们不表示针目倾斜方向，也不是同一行两边各加 1 针。

每织一行都会换工作方向。工具内部用两条固定布边计算位置，再按全局行号换算成当行的“行首／行尾”。间隔为奇数、中间平织为奇数或首次减针行不同，都可能让同一布边在下一事件显示为相反的行首／行尾。

加针的首次位置以第一加针行的操作顺序选定。单侧后续保持布边；左右交替后续每个事件换布边。

减针有三种配置：

- **沿用加针侧**：第一减针在最后一次加针的布边；若加针为交替，则后续减针从这条布边向回交替；起针与结束针数相同时，这相当于逆序回收加针事件。单侧则继续同一布边。
- **单侧减针**：按首次减针的行首／行尾独立选定布边，后续始终同侧。
- **左右减针**：首次布边独立选定，后续每个事件换边。

只有“仅减针段”时没有加针历史，“沿用加针侧”不可选，采用独立减针位置。上述规则用于表达用户指定的形状，不声称官方 Sophie 包含全部这些变体。

## 6. 表格初始化与结束

设起针 S、最宽 M、结束 E、间隔 I、首次加针 A、减针段首减 D、中间平织 C、末尾平织 T。

- 加针次数为 M − S；加针段行数为 A + (M − S − 1) × I。
- 加针事件为段内 A, A + I, A + 2I …，每次加 1 针，达到 M 时结束此段。
- 整条模式再追加 C 行最宽针数平织。
- 减针次数为 M − E；减针段行数为 D + (M − E − 1) × I。
- 减针事件为段内 D, D + I, D + 2I …，每次减 1 针，达到 E 时结束此段。
- 最后追加 T 行平织。C 不包含减针段开头已有的 D − 1 行。
- 若记录收针，在整条或仅减针段末尾再加 1 个“收 E 针”的可勾选行，织后针数为 0。它记录完成收针，不规定收针技法。
- 仅加针段不追加收针行。

起针动作不计入行号；一行是从一端织到另一端，不是来回两次或一道搓板纹。整条模式使用连续全局行号；单段模式的表格行号就是该段行号。变针行立即更新织后针数。

收针行纳入表格总数、完成进度和“已完成行数”，长度估算则排除这一行。长度仅按行密度粗估，不能保证成品尺寸。最后平织行数、首次减针行和收针安排须来自个人织图，不从截图自动推断。

## 7. 旧进度迁移

存档外层仍使用 version: 1；当前计数参数为 rules: 3，要求自有合法 turnAfterRow 字段，0 表示没有中途转折。旧 rules: 2 缺少该字段时按 0 恢复。旧参数没有 rules 时，恢复过程中只迁移操作细节：

- 保留原起针、最宽、结束、事件行号、间隔、中间平织、末尾平织和完成勾选；旧示例的 327 行仍为 327 行。
- 保留已有 incLead、decLead，包括旧默认的 3 针前导。原先未填位置的旧参数使用可读的新建议值。
- 对 6 针起织、末尾滑 3 针的旧计划，首次加针前导补为 2；对结束 6 针、末尾滑 3 针的旧计划，末次减针前导补为 2。
- 旧加针数字口径迁移为针内加针，减针采用沿用加针侧，finish 设为 none。不会为旧进度自动插入收针行。

旧用户可在设置中选择追加收针。原行表是新行表的完整前缀、连续完成行数未变时，保留全部逐行勾选，包括跳行记录；纯操作位置或手法调整也保留勾选。改变针数或事件计划等不兼容修改时，先确认以设置中的连续完成行数替换旧逐行记录。

当前小工具存储键为 sophie-minitool-v1。同一浏览器环境可读取原本地预览的 sophie-preview-v1，下次保存写入新键且保留旧值。浏览器与小红书容器并非同一存储环境；这不代表浏览器进度自动迁入小红书。

## 8. 交互与本机保存

顶部只显示当前行、完成数量和保存状态；不放图例。当前行用圆角、柔和投影、加粗行号和“当前”标记突出，保留黄色／绿色分组底色，行号与操作列之间有分隔线。

点一行只切换这一行，再点恢复。大按钮完成第一行未完成的行；有跳行时保留记录并定位首个未完成行，不自动填满之前的行。“退回一行”取消最后一个连续完成行。输入行号用于查看，不更改进度。收针行的大按钮显示“收好了”。

进入计数、完成或撤回、返回设置以及点击“回到当前行”时定位当前行，手动浏览不持续抢回滚动位置。列表按可见范围渲染，首尾留白帮助第一行和最后一行居中。输入参数时只更新状态，不重建输入框或主动关闭键盘。

每次操作先成功写入 localStorage，再更新勾选；保存失败保留原进度。读取参数缺失、无效或损坏时，不以默认表静默替换。仅保存一条作品，无账号或跨设备同步；清理对应本地存储可能丢失记录。

## 9. 小工具构建与验证范围

当前运行入口为 src/index.html，使用同目录相对资源，无后端、CDN 或联网请求。npm run preview 服务与 ZIP 使用相同源码；npm run build 打包 index.html、样式和六个脚本，检查禁止能力、相对资源、脚本语法及包大小。旧原生小程序目录不作为当前小工具发布入口。

[小红书官方小工具容器能力说明](https://fe-video-qc.xhscdn.com/fe-platform-file/104101b8323q4m0uaga06277180ac7t8006ptl0e12ek1g)将小工具定义为受限沙箱中的 HTML／CSS／JavaScript 应用。浏览器预览可检验界面和计数交互，不能证明小红书容器中的实际表现。

测试范围应覆盖：截图针数与色组、针内／针间原针守恒、首次和末次变针、行尾排列、零针块省略、无效位置拦截、单侧／交替布边、全局行方向及转折、收针结束、旧存档迁移、修改计划时进度保留、跳行与撤回、保存失败回滚、构建资源和能力约束。测试结果以当次运行记录为准，本文不声明已完成真机验收。

发布前仍需在小红书手机端检查关闭重开后进度恢复、输入与键盘、长列表滚动、当前行定位、收针后的完成状态，并邀请熟悉 Sophie 的用户按自己持有的织图试用。公开发布定位为“配合自己的织图使用的行数计数工具”。

## 10. v0.4 形状预览

设置提交先进入围巾预览，确认后才写入存档。预览直接使用实际行表的针数变化和布边，支持单侧、左右交替及部分段落；每 10 cm 针密度与行密度决定长宽比例。六种纱色只影响预览外观，不改变表格分组或勾选。具体计算、保存边界与验收结果见 [围巾形状预览](shape-preview.md)。

## 11. v0.5 中途转折

加针阶段可将最近连续完成行设为最宽处，默认在原下一次变针行开始减针。turnAfterRow 保存锚点，既有行号、阶段、针数与布边原样保留；先预览再保存，并明确清除锚点之后的勾选。转折后固定会改写加针历史的参数，未来修改也需保持所有已勾选行的实体织法一致。交互、字段与验证见 [设为最宽处](turn-point.md)。
