## 审查发现及修复

- 首页操作失败原来只写入控制器状态；现已在列表外固定区域展示错误，滚动到第三条也能看到。
- 外部标签页保存原来不会刷新作品摘要；现已监听作品库的 storage 事件，刷新首页与切换列表，同时保留当前作品的陈旧 revision 保护。
- 删除确认组件同步异常原来会留下忙碌状态；现已恢复操作并显示失败提示。最近打开顺序保存失败时，仍能读取已有记录并说明错误。
- 首页重绘原来丢失列表滚动位置；现已保留作品列表与管理列表滚动位置，小屏第三条菜单已实际验证。
- 首卡主按钮受普通按钮背景覆盖；现已明确主按钮底色，最终截图可辨识。
- 原生确认弹窗阻塞了本轮浏览器自动操作；最终版本使用页内确认及提示，包含标题、取消/确认、Escape 关闭和 Tab 焦点约束。取消后恢复管理列表焦点；源码另补齐等待删除保存完成后恢复焦点，其他确认框仍打开时不抢夺焦点。

## 尚未验证的边界

本轮只验证本机浏览器及自动测试。尚未验证小红书 iOS/Android 真机容器、Chrome 61 兼容性、软键盘与系统安全区、App 被回收后的恢复，以及完整键盘和屏幕阅读器体验。成功删除后的异步焦点恢复已在源码补齐并审读，完整键盘体验仍未验收。共享保存锁依赖容器提供 IndexedDB，真机需核对其可用性。

进度仍只保存在本机，没有账号或跨设备同步；清理对应存储可能丢失记录。围巾预览按参数和密度估算，不替代实际编织结果或个人织图。真机验收与发布尚未执行。
