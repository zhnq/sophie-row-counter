# v0.10.6 行内左右侧提示

日期：2026-10-03。交付对象：小红书离线 H5 ZIP，以及额外的单文件 HTML。

## 变化

每个变针行由原有 `fabricEdge` 显示具体布边。以第 1 行从右向左织的朝向为固定参照，0 为左侧、1 为右侧；翻面后左右标签保持，行首／行尾按全局行号变化。

加针块保留真实原针序号，下方显示“右侧加针 · 行尾”等提示；减针块显示“左侧减针／右侧减针”，并保留行首／行尾。设置里的单侧／左右交替仍是计划选项，不代替具体行提示。M1L／M1R 针目倾斜与布边标签独立。

加针方式帮助补充简短朝向说明；布边图及事件时间线显示对应侧别。仅减针段以该段第 1 行为参照，不声称已推断原加针历史。

不改变行号、针数、变针位置、存档键或规则版本。旧存档由参数重新生成显示文字，稀疏勾选保留；`sameRowOperations` 仍按真实织法保护已织部分。与 v0.10.5 的 ZIP 比较，仅 `pattern.js`、`app.js` 两个资源不同，首次空库兼容修复继续保留。
